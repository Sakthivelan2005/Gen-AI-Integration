# Gen AI Notes

## Data Types (Define Type of Data)

* **Number:** `int`, `float`, `complex` *(immutable)*
* **Text:** `string` *(immutable)*
* **Boolean:** `bool` *(immutable)*
* **List:** `list` *(mutable)*
* **Dictionary:** `dict` *(mutable)*
* **Set:** `set` *(mutable)*
* **Tuple:** `tuple` *(immutable)*
* **NoneType:** `NoneType` *(immutable)*

---

## Functions
> Block of code used to perform a specific task.

* **Pre-defined:**
  * `filter()`
  * `map()`
  * `reduce()` *(returns a single value by traversing through elements)*
* **User-defined:**
  * Requires Function Definition and Function Call
* **Anonymous:**
  * `lambda`

## NumPy (Numerical Python)

* Based on $n$-dimensional arrays.
* Used to generate multi-dimensional data structure/arrays.
* Supports up to **32 dimensions**.
* Frequently used for image processing and high-performance mathematical computing.
* Core foundation for AI, ML, and Chatbot pipelines.

---

## Pandas

* **DataFrame:** 2-Dimensional labeled data structure
* **Series:** 1-Dimensional labeled array

### Indexing & Selection
* `df.loc[]` — Label-based indexing *(negative indexing is not supported)*
* `df.iloc[]` — Integer position-based indexing
